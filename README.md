
# Telecom Customer Churn Analysis

## Project Overview
This project analyzes telecom customer data to understand customer churn patterns and identify factors associated with customers leaving the service.

## Tools & Technologies
- Python
- Pandas
- Matplotlib
- Google Colab

## Key Findings
- Overall customer churn rate was 26.54%.
- Month-to-month contracts had a churn rate of 42.71%.
- Customers who churned had average monthly charges of $74.44.
- Churned customers had an average tenure of 17.98 months.
- Electronic check users had a churn rate of 45.29%.

## Project Workflow
- Data loading and exploration
- Missing values and duplicate checks
- Churn rate calculation
- Contract type analysis
- Monthly charges and tenure analysis
- Payment method analysis
- Data visualization

## Conclusion
The analysis found higher churn rates among month-to-month contract customers and electronic check users. These patterns can help guide further customer retention analysis.
